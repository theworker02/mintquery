# mintquery

Mint HTML/Markdown query fragments safely for docs pipelines.

**Site:** https://theworker02.github.io/mintquery/

## Install / run

```bash
git clone https://github.com/theworker02/mintquery.git
cd mintquery
node src/cli.js
node --test
```
